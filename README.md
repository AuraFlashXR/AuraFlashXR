# 🚀 AuraFlashXR

**Ultra-low latency Direct OpenXR & SteamVR PCVR streaming runtime for Meta Quest 3 / 3S / Pro / 2.**
Bypasses compositor overhead with hardware-tuned NVENC multi-slice encoding, unified SteamVR driver telemetry, 1-click ADB/APK deployment, automated microphone passthrough (`AuraFlashXR-MIC`), and a modernized Dark Mode UI — now with a **native Rust OpenXR Quest client (v0.2, dual OpenGL / Vulkan builds)** and a unified **TOOLBOX OPENXR** launcher panel.
